2. CONTEXTE ET ENJEUX
──────────────────────
Habitat Services Collectivités est un prestataire spécialisé dans la
gestion externalisée de services aux collectivités territoriales :
maintenance des espaces verts, gestion des équipements sportifs, entretien
des bâtiments publics et logistique événementielle. La société compte
240 collaborateurs, 85 collectivités clientes actives et traite environ
1 200 interventions par mois.

L'extranet client actuel, développé en 2017, permet aux collectivités
de déposer des demandes d'intervention et de consulter les compte-rendus.
Il est devenu obsolète techniquement (jQuery, PHP 7, base MySQL non
maintenue) et fonctionnellement insuffisant : absence de suivi temps
réel, pas de tableau de bord, interface non responsive, temps de
chargement excessifs.

Par ailleurs, la direction commerciale souffre de l'absence d'outil
de pilotage consolidé : les données d'activité sont extraites
manuellement depuis 3 outils différents (GMAO, extranet, ERP) pour
produire des reportings Excel mensuels peu fiables.

Le présent appel d'offres vise à :
  1. Remettre à niveau l'extranet client sur une stack moderne
  2. Déployer un espace décisionnel Power BI pour les managers HSC
     et pour les responsables des collectivités clientes

Budget global : 55 000 € HT — enveloppe non extensible.
Durée de réalisation : 4 mois.

3. PÉRIMÈTRE FONCTIONNEL
─────────────────────────

3.1 Extranet client — espace collectivité
  — Authentification sécurisée par compte collectivité (login / mot de
    passe avec lien de réinitialisation) ; intégration SSO Azure AD
    possible si le candidat peut l'intégrer dans l'enveloppe
  — Tableau de bord collectivité : compteurs d'interventions en cours,
    planifiées, soldées, taux de satisfaction moyen
  — Création de demande d'intervention en ligne :
      · Formulaire structuré (type de prestation, site, urgence, descriptif)
      · Dépôt de photos ou documents associés
      · Confirmation automatique par email avec numéro de ticket
  — Suivi en temps réel du statut des demandes :
      Reçue → Planifiée → En cours → Réalisée → Validée → Soldée
  — Consultation des compte-rendus d'intervention (PDF générés)
  — Historique des interventions sur 24 mois avec filtres et export CSV
  — Messagerie contextuelle par demande entre le responsable collectivité
    et le chargé de compte HSC
  — Interface 100 % responsive (tablette et mobile)

3.2 Espace décisionnel Power BI — managers HSC
  — Tableau de bord consolidé de l'activité nationale :
      · Volume d'interventions par type, par région, par collectivité
      · Taux de respect des délais d'intervention (SLA contractuels)
      · Taux de satisfaction client (note issue du formulaire post-intervention)
      · Chiffre d'affaires par collectivité et évolution mensuelle
      · Alertes sur collectivités à risque (retards, insatisfactions répétées)
  — Accès en lecture pour les responsables de collectivités :
    vue restreinte à leurs propres indicateurs uniquement
  — Données alimentées depuis 3 sources : SQL Server (GMAO), PostgreSQL
    (nouvel extranet), API REST de l'ERP (spécifications fournies)
  — Rafraîchissement automatique quotidien (scheduled refresh Power BI)
  — Partage via Power BI Service (licences Microsoft 365 HSC existantes)

3.3 Contrainte de périmètre dans l'enveloppe
  Le budget de 55 000 € est très contraint pour ce double périmètre.
  Les candidats sont invités à proposer un cadrage précis et réaliste :
  — Fonctionnalités incluses dans le périmètre ferme
  — Fonctionnalités reportées en option (chiffrées séparément)
  — Choix d'architecture économiques justifiés (ex. : hébergement mutualisé,
    utilisation d'un framework front-end léger)

4. EXIGENCES TECHNIQUES
─────────────────────────

4.1 Stack technique attendue
  — Front-end : Angular 17+ ou React 18+ (le candidat justifie son choix)
  — Back-end : .NET Core 8 ou Python FastAPI (selon compétences équipe)
  — Base de données : SQL Server 2022 (existant HSC) ou PostgreSQL
  — Décisionnel : Power BI Desktop + Power BI Service (licences Microsoft
    365 HSC — environnement tenant existant)
  — Hébergement : Azure (abonnement existant HSC) — App Service ou
    conteneur Docker selon proposition du candidat
  — CI/CD : pipeline GitHub Actions ou Azure DevOps (environnements
    développement et production)

4.2 Intégrations existantes
  — GMAO (Maximo 7.6) : extraction SQL Server des bons de travail
  — ERP (Sage 100c) : API REST fournie par l'éditeur (token d'accès fourni)
  — Messagerie Microsoft 365 : envoi des notifications via Graph API

4.3 Sécurité et conformité
  — Conformité RGPD : les données collectivités et agents sont des
    données personnelles — le prestataire fournit une analyse des
    traitements et les clauses de sous-traitance adaptées
  — Authentification sécurisée avec gestion des sessions et expiration
  — Journalisation des connexions et actions sensibles
  — Hébergement des données en France (Azure France Central)
