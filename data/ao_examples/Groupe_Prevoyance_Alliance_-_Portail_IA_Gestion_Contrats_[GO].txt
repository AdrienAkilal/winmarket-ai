2. CONTEXTE ET ENJEUX
──────────────────────
Groupe Prévoyance Alliance est un acteur de référence de la prévoyance
collective en France, avec 420 000 contrats actifs, 18 000 entreprises
clientes (TPE, PME et grands comptes) et un réseau de 340 agents
commerciaux répartis sur 28 agences régionales.

Aujourd'hui, la gestion des contrats repose sur un progiciel central
vieillissant (PrévoSoft v4, déployé en 2014) et une multitude d'outils
bureautiques non interconnectés (Excel, SharePoint, emails). Ce dispositif
génère des frictions significatives :

  • Délai moyen de souscription : 11 jours ouvrés (objectif : ≤ 3 jours)
  • Taux d'erreur en saisie des avenants : 14 % (source : audit interne 2024)
  • Temps consacré à la recherche documentaire : 35 % du temps agent
  • Absence d'outil de pilotage commercial unifié pour les managers

Face à ces constats, Groupe Prévoyance Alliance souhaite déployer un
portail web de nouvelle génération intégrant des briques d'Intelligence
Artificielle pour automatiser, fiabiliser et accélérer l'ensemble du cycle
de vie des contrats de prévoyance collective.

Le budget global alloué à ce projet est de 370 000 € HT sur 20 mois,
réparti comme suit :
  — Phase 1 — Portail socle + souscription assistée (10 mois) : 210 000 € HT
  — Phase 2 — Modules IA + pilotage commercial (10 mois) : 160 000 € HT

3. PÉRIMÈTRE FONCTIONNEL DÉTAILLÉ
────────────────────────────────────

3.1 Module Souscription Assistée
Le portail devra permettre aux agents commerciaux de créer, compléter
et soumettre une demande de souscription entièrement en ligne :

  a) Formulaire dynamique intelligent
     — Adaptation automatique des champs selon le profil entreprise cliente
       (effectif, secteur NAF, catégorie de garanties souhaitées)
     — Pré-remplissage des données entreprise via API SIRENE (INSEE)
     — Calcul de la prime estimée en temps réel avec explication des paramètres
     — Génération automatique du projet de contrat PDF dès validation

  b) Collecte et vérification documentaire
     — Dépôt de pièces justificatives (Kbis, RIB, DADS, bulletins de paie)
     — OCR et extraction automatique des données clés par LLM
       (raison sociale, SIRET, effectif, masse salariale, convention collective)
     — Contrôle de cohérence des données extraites vs formulaire saisi
     — Alertes automatiques en cas d'incohérence détectée

  c) Workflow de validation multi-niveaux
     — Validation agent → soumission underwriting → accord direction technique
     — Notifications email et in-app à chaque étape
     — Délai de traitement affiché en temps réel avec engagement de réponse SLA
     — Archivage automatique des échanges et versions successives du dossier

3.2 Module Gestion et Suivi des Contrats
  — Tableau de bord agent : portefeuille complet, alertes d'échéance, KPIs
  — Consultation et téléchargement de l'ensemble des pièces contractuelles
  — Gestion des avenants : modifications d'effectif, de garanties, de bénéficiaires
  — Historique complet des échanges et des modifications avec horodatage
  — Export des données au format CSV / Excel pour les reportings RH client

3.3 Module Assistant IA Documentaire (RAG)
Il s'agit du cœur différenciant de la solution. Le titulaire développera
un assistant conversationnel en langage naturel permettant aux agents de :

  a) Interroger la base documentaire de GPA
     — Convention collective applicable à un secteur NAF donné
     — Garanties couvertes par un type de contrat spécifique
     — Procédures internes de gestion des cas particuliers (invalidité,
       prévoyance lourde, portabilité)
     — Réglementation en vigueur (ANI 2013, loi Évin, accord de branche)

  b) Générer des livrables commerciaux
     — Proposition commerciale personnalisée en 1 clic (format DOCX / PDF)
     — Fiche de synthèse garanties adaptée au prospect
     — Mail de relance commercial pré-rédigé et contextualisé
     — Comparatif produits GPA vs offre concurrente (sur base fournie)

  c) Caractéristiques techniques du moteur RAG
     — Base documentaire : 2 400 documents (notices, contrats-types, circulaires,
       fiches produits, guides réglementaires) à indexer dès la phase 1
     — Mise à jour de la base documentaire : interface d'administration simplifiée
     — Modèle LLM : GPT-4o, Claude 3.5 Sonnet ou équivalent accessible via API
     — Mémoire conversationnelle : contexte conservé sur 10 tours de dialogue
     — Traçabilité : chaque réponse citée avec la source documentaire précise
     — Langue : français exclusivement

3.4 Module Pilotage Commercial (Managers)
  — Tableau de bord régional : taux de souscription, délais, taux d'erreur
  — Alertes automatiques sur contrats à risque (impayés, résiliations proches)
  — Rapports mensuels auto-générés exportables (PDF + PowerPoint)
  — Vue nationale consolidée pour la direction commerciale
  — Accès contrôlé par région et par niveau hiérarchique (RBAC)

4. EXIGENCES TECHNIQUES ET CONTRAINTES
────────────────────────────────────────

4.1 Architecture cible
  — Application web monopage (SPA) : React 18+ ou Angular 17+
  — Backend API REST : Python (FastAPI ou Django REST Framework)
  — Base de données principale : PostgreSQL 15+ avec chiffrement at-rest
  — Base vectorielle pour RAG : ChromaDB, Qdrant ou équivalent
  — Hébergement : Microsoft Azure (région France Centre — Paris)
  — Orchestration : Docker + Kubernetes (AKS) pour les composants IA
  — CI/CD : pipeline GitLab ou GitHub Actions avec déploiement automatisé
    sur environnements de développement, recette et production
  — Supervision : stack Grafana + Prometheus, alertes PagerDuty

4.2 Sécurité et conformité
  — Authentification SSO via Azure Active Directory (SAML 2.0 / OpenID Connect)
    intégré au tenant GPA existant
  — Gestion des habilitations par rôle (agent, manager, underwriter, admin)
  — Chiffrement des données en transit (TLS 1.3) et au repos (AES-256)
  — Journalisation complète des accès et actions (audit trail RGPD)
  — RGPD : conformité by design — registre de traitement, durées de
    conservation configurables, procédure de droit à l'oubli automatisée
  — Tests de pénétration (pentest) à la livraison Phase 1 et Phase 2,
    conduits par un prestataire tiers homologué

4.3 Performances et disponibilité
  — Temps de chargement des pages : < 2 secondes (P95, réseau ADSL standard)
  — Temps de réponse de l'assistant IA : < 5 secondes (P90)
  — Disponibilité : 99,5 % hors maintenance programmée (SLA contractuel)
  — PRA : RPO ≤ 2h, RTO ≤ 4h
  — Capacité : 340 utilisateurs simultanés en heure de pointe

4.4 Intégrations systèmes existants
  — PrévoSoft v4 : synchronisation bidirectionnelle via API REST (fournie
    par l'éditeur — documentation disponible à la signature du NDA)
  — API SIRENE INSEE : pré-remplissage données entreprise
  — Microsoft 365 : intégration Outlook (envoi notifications) et Teams
    (canal de suivi dossiers)
  — Docusign : signature électronique des contrats et avenants

4.5 Certifications et conformité requises
  ✦ RGPD — conformité by design OBLIGATOIRE (analyse d'impact AIPD attendue)
  ✦ Pratiques sécurité alignées ISO 27001 souhaitées (certification non requise)
    — Le candidat devra fournir sa politique sécurité interne et son plan
      d'assurance qualité sécurité (PASSI n'est pas exigé)
  ✦ RGAA 4.1 niveau AA pour les interfaces publiques (portail client futur)

  Note : aucune exigence SecNumCloud, HDS ou NF Z 42-013 pour ce marché.
  Les données traitées sont des données personnelles standard (contrats
  de prévoyance collective), hors données de santé nominatives.
