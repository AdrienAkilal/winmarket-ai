# Méthodologie interne de réponse aux appels d'offres

## Objectif
Cette méthode décrit la manière dont NovaSoft Conseil analyse et décide de répondre ou non à un appel d'offres. Elle sert de base au moteur de scoring WinMarket AI.

## Étape 1 - Qualification rapide
Le dossier est lu pour identifier l'objet, le client, le budget, les délais, le périmètre, les compétences attendues, les livrables, les contraintes de réponse, les certifications exigées et les clauses contractuelles sensibles. Un premier filtre élimine les dossiers hors périmètre ou manifestement irréalistes.

## Étape 2 - Matching avec le référentiel interne
Les exigences sont comparées aux services, compétences, références, méthodologies et capacités internes. L'analyse doit produire des preuves : référence similaire, compétence disponible, certification détenue ou non, capacité de démarrage, expérience sectorielle.

## Étape 3 - Analyse économique
Le budget est comparé au niveau d'effort estimé. Un projet web métier complet sous 100 000 € est rarement rentable. Un projet RAG industrialisé sous 80 000 € est risqué. Les projets avec forte marge récurrente ou potentiel de maintenance sont valorisés.

## Étape 4 - Analyse risque
Les risques portent sur le délai, la complexité technique, les dépendances SI client, les clauses contractuelles, les pénalités, les certifications, la disponibilité des ressources et la maturité du besoin. Les risques doivent être explicités dans la décision.

## Étape 5 - Décision
GO : le projet est aligné avec les offres, rentable, réalisable et stratégiquement pertinent.
GO sous réserve : le projet est intéressant mais nécessite clarification, réduction de périmètre, ajustement délai, partenaire, renfort ou arbitrage commercial.
NO-GO : le projet est hors périmètre, non rentable, trop risqué ou bloqué par une certification/contrainte obligatoire.

## Seuils recommandés
Score >= 80 : GO.
Score entre 60 et 79 : GO sous réserve.
Score < 60 : NO-GO.
Toute règle bloquante prime sur le score.

## Règles bloquantes
Certification obligatoire absente, budget inférieur au minimum viable, délai manifestement impossible, compétence critique absente, charge équipe supérieure à 95 %, clauses contractuelles disproportionnées, absence de validation humaine possible, obligation d'hébergement qualifié non disponible.
