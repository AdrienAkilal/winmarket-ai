# Service - Conception et développement de plateformes web métiers

## Positionnement du service
NovaSoft Conseil est une ESN française indépendante spécialisée dans la conception, le développement et la maintenance de plateformes web métiers critiques. Ce service couvre les portails clients, extranets partenaires, intranets opérationnels, applications de gestion interne, plateformes SaaS B2B et outils de pilotage destinés aux directions métiers. L'objectif est de transformer un processus métier complexe en application web robuste, maintenable, sécurisée et industrialisable.

## Périmètre fonctionnel couvert
Nous intervenons sur l'ensemble du cycle de vie projet : cadrage du besoin, ateliers métiers, conception UX/UI, rédaction des spécifications fonctionnelles et techniques, architecture applicative, développement front-end et back-end, intégration avec le SI existant, recette, formation, mise en production et maintenance évolutive. Les projets typiques concernent la dématérialisation de parcours, la centralisation de données opérationnelles, la gestion d'un workflow métier, le suivi de dossiers, la création de tableaux de bord ou la mise à disposition d'un espace sécurisé pour des clients ou partenaires.

## Technologies maîtrisées
Front-end : React, Angular, Vue.js, TypeScript, HTML5, CSS3, Tailwind, design systems internes.
Back-end : Java Spring Boot, Python FastAPI/Django, .NET Core, Node.js/NestJS.
Bases de données : PostgreSQL, SQL Server, Oracle, MongoDB, Redis.
Intégration : API REST, GraphQL, OAuth2, SSO, SAML, ETL léger, webhooks.
Industrialisation : Docker, GitLab CI, GitHub Actions, SonarQube, Kubernetes selon contexte.

## Méthode d'exécution
Nous privilégions une approche agile pragmatique : sprint de cadrage initial, backlog priorisé, livraison incrémentale, démonstration toutes les deux semaines, recette continue et validation métier progressive. Pour les organisations plus réglementées, nous pouvons fonctionner en cycle hybride avec jalons formels, dossiers de conception, plans de tests et procès-verbaux de recette.

## Équipe type mobilisable
Un projet standard mobilise un chef de projet, un product owner proxy, un architecte solution, deux à six développeurs full-stack, un UX/UI designer, un QA engineer et un DevOps selon niveau d'industrialisation. Nous pouvons renforcer le dispositif avec un expert sécurité, un data engineer ou un consultant conduite du changement.

## Livrables standards
Note de cadrage, cartographie des processus, backlog détaillé, maquettes UX/UI, dossier d'architecture technique, code source documenté, guide d'installation, cahier de recette, plan de tests, documentation utilisateur, dossier d'exploitation, support de formation et bilan de transfert.

## Conditions de réussite
Le projet est considéré comme très favorable lorsque le client dispose d'un sponsor métier identifié, d'utilisateurs référents disponibles, d'un périmètre MVP clairement priorisé, d'un accès documenté aux API du SI cible et d'un délai minimum de 4 à 6 mois pour une plateforme complète. Un budget inférieur à 120 000 € est généralement insuffisant pour une plateforme critique avec architecture sécurisée, intégration SI et maintenance initiale.

## Red flags métier
Périmètre fonctionnel très large sans priorisation, délai inférieur à 10 semaines pour une application complète, absence d'interlocuteur IT côté client, exigence SecNumCloud obligatoire, reprise massive de données non cadrée, pénalités de retard disproportionnées, obligation de résultat sur un SI tiers non maîtrisé.
