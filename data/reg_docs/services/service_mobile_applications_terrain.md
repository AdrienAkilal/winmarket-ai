# Service - Applications mobiles et outils terrain

NovaSoft Conseil développe des applications mobiles Android/iOS et des Progressive Web Apps destinées aux équipes terrain, techniciens, commerciaux, inspecteurs, livreurs ou partenaires. Les projets incluent la consultation de données, la saisie de formulaires, la prise de photo, la signature, la géolocalisation, le mode hors connexion et la synchronisation avec un back-office.

Technologies : React Native, Flutter, Ionic, API REST, Firebase, PostgreSQL, stockage local chiffré, notifications push, authentification SSO. Les équipes savent concevoir une application terrain couplée à une plateforme web d'administration.

Un projet mobile est favorable lorsque le périmètre fonctionnel est limité, que les devices sont connus, que les règles offline sont explicites et que le client accepte une phase pilote terrain. Il devient risqué lorsque l'application doit remplacer un outil critique dans un délai court, intégrer des matériels spécifiques non documentés ou fonctionner dans des zones sans réseau avec synchronisation complexe non cadrée.
